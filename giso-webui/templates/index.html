Golden ISO upgrade guide

Use an approved maintenance window. Verify the exact platform, source release, target release and supported upgrade path in Cisco documentation. Confirm console access, redundancy health, recovery media and a current configuration backup. The router may reload or restart processes.
  1. Download and transfer the ISO

    Download the image from this archive, then transfer it with SFTP/SCP to /harddisk:/ on the router.

  2. Verify the transferred file

    Compare the router MD5 with the MD5 shown in this archive.

    show md5 file /harddisk:/IMAGE.iso
  3. Run pre-checks
    show version
show platform
show redundancy
show install request
show install active summary
show install committed summary
show alarms brief system active
dir harddisk:

    Do not continue while another install transaction is active or the platform is unhealthy.

  4. Start the GISO replacement
    install replace /harddisk:/IMAGE.iso
    Read and confirm the router prompt. Keep console access available while the operation runs.
    5. 
      
  5. Monitor and verify
    show install request
show install history last transaction verbose
show version
show platform
show install active summary
    6. 
      
  6. Commit after validation
    install commit
show install committed summary
    Commit only after software, hardware, redundancy, alarms, routing and traffic checks are successful.

Software rollback guide

    
Rollback can reload the router and restore older configuration state. Keep console access available, preserve diagnostic logs and verify the exact rollback syntax for the platform and release before continuing.

    
    
    
      
  1. Inspect state and available rollback points
    show install request
show install rollback list-ids
show install history last transaction verbose
    Record the current active and committed package sets and inspect the changes for the selected transaction ID.
    2. 
      
  2. Abort an un-applied package request when appropriate
    install package abort latest
    Use abort only for a pending package operation supported by the exact release. It is not a substitute for rolling back already applied software.
    3. 
      
  3. Stage or start the rollback
    show install rollback id <TRANSACTION-ID> changes
install package rollback <TRANSACTION-ID>
    show install request
install apply reload
    Use show install request and Cisco documentation to decide whether reload or restart is required.
    4. 
      
  4. Validate before committing
    show version
show platform
show redundancy
show install active summary
show alarms brief system active
    Validate routing, forwarding, services and traffic. Commit only after the recovered state is healthy.
    5. 
      
  5. Commit the validated rollback
    install commit
show install committed summary
