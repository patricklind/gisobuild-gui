CISCO IOS XR

Golden ISO upgrade guide

Use a maintenance window. Confirm console access, redundancy health and a current configuration backup before starting. The router may reload or restart processes.
  1. Download and transfer the ISO

    Download the image from this archive, then transfer it with SFTP/SCP to /harddisk:/ on the router.

  2. Verify the transferred file

    Compare the router MD5 with the MD5 shown in this archive.

    show md5 file /harddisk:/IMAGE.iso
  3. Run pre-checks
    show version
show platform
show install request
show install active summary
dir harddisk:

    Do not continue while another install transaction is active or the platform is unhealthy.

  4. Start the GISO replacement
    install replace /harddisk:/IMAGE.iso
    Read and confirm the router prompt. Keep console access available while the operation runs.

  5. Monitor and verify
    show install request
show install history last transaction verbose
show version
show platform
show install active summary

  6. Commit after validation
    install commit
show install committed summary
    Commit only after routing, MPLS/MPLS-TE and platform health checks are successful.
